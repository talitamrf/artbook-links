# ✦ Artbook Links

Uma landing page pessoal para reunir meus principais links, inspirada na estética de artbooks japoneses, character profiles e menus de JRPGs.

Uma landing page pessoal para reunir meus principais links, inspirada na estética de **artbooks japoneses, character profiles e menus de JRPGs**.

O projeto começou como uma alternativa mais personalizada a páginas tradicionais de links e acabou virando uma espécie de **perfil de personagem em formato de artbook digital**.

## ☾ Sobre o projeto

A página foi desenvolvida com foco em uma estética editorial inspirada em materiais de jogos japoneses, utilizando:

- layout de livro aberto;
- tipografia serifada;
- paleta em tons de creme e roxo;
- elementos decorativos como luas, estrelas e divisores;
- character profile;
- lista de franquias favoritas;
- GIFs de personagens favoritos;
- arquivo com redes sociais e outros perfis.

A página é dividida em duas partes.

## ✦ Page 01 — Character Profile

Apresenta informações pessoais, interesses e referências que fazem parte da identidade visual do projeto.

Inclui:

- About Me;
- Favorite Quote;
- Favorite Series;
- Favorite Characters;

## ✦ Page 02 — Link Archive

Reúne meus principais perfis e formas de contato:

- GitHub;
- LinkedIn;
- Steam;
- Your Game Profile;
- Movie Profile;
- Twitter / X;
- Instagram;
- E-mail.

## ◇ Tecnologias

- HTML5
- CSS3
- CSS Grid
- Flexbox
- Media Queries
- `clamp()` para responsividade

O projeto atualmente não utiliza frameworks ou bibliotecas JavaScript.

## ☾ Responsividade

O layout foi pensado para funcionar como um **artbook aberto em telas maiores**.

Em resoluções menores, as páginas passam a ser exibidas verticalmente para manter a leitura e a composição visual.

Elementos gráficos como a personagem principal e a lua utilizam unidades responsivas para preservar o layout em diferentes tamanhos de tela.
